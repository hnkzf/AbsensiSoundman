# AbsensiSoundman

Isi Nama (nama harus sama untuk seterusnya)

Klik buka kamera

Menggunakan Google Apps Script untuk backend API, di-integrasikan dengan Github Pages untuk halaman frontendnya.
Input data dari frontend diteruskan oleh backend ke Google Drive untuk menyimpan foto, dan ke Google Spreadsheet untuk menyimpan data detail anggota.
